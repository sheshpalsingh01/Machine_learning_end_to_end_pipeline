ml pipeline
preprocessing -> training -> evaluation -> dvc

dvc stage1--stage2 --> stage3

dvc stage add -n preprocess \ -p preprocess.input,preprocess.output \ -d src preprocess.py -d data/raw/data.csv \-o data/precessed/data.csv \ python src/preprocess.py

-n -> new stage
-p -> track the parameter
-d -> depandancy of stage
-o -> output of the stage 

dvc stage add -n preprocess \
    -p preprocess.input,preprocess.output \
    -d src/preprocess.py \
    -d data/raw/data.csv \
    -o data/processed/data.csv \
    "cd src && python preprocess.py"


dvc stage add -n train \
    -p train.data,train.model,train.random_state,train.n_estimators,train.max_depth \
    -d src/train.py \
    -d data/processed/data.csv \
    -o models/model.pkl \
    "cd src && python train.py"

dvc stage add -n evaluate \
    -d src/evaluation.py \
    -d data/processed/data.csv \
    -d models/model.pkl \
    "cd src && python evaluation.py"


dvc dag 
dvc repro # run entire pipeline


The dvc stage add command is used to define stages in a machine learning or data pipeline. These stages represent steps like data preprocessing, model training, or evaluation
